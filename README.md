## Local preview

Serve this directory with a static HTTP server, for example:

```sh
python -m http.server 8000
```

Open http://localhost:8000. No build or package installation is required.

## Structure

- `index.html`: content, metadata, and accessible navigation.
- `style.css`: responsive styling and reduced-motion support.
- `index.js`: mobile navigation, active section links, and optional animations.
- `assets/`: portrait, project screenshots, and downloadable CV.

Fonts, icons, and optional GSAP animations use external CDNs. All four projects and their links remain visible without JavaScript or GSAP. The download button is labelled CV to match the existing two-page document.

## Publishing and rollback

GitHub Pages is the preferred portfolio address. GitHub Pages is enabled for this repository; verify the Pages deployment after merging source changes. The website metadata and profile README use the GitHub-hosted URL.

Use reviewed commits and pull requests. To undo an applied change, revert its merge or squash commit on a new branch, verify the result, and redeploy through the same hosting setup. Avoid force-pushing shared history.
